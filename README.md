설계: `../설계지시안_엘니뇨어부게임_v1.2.md` · Supabase 기록: `supabase/설정기록_S6.md` · 문구 원장: `../시안/elnino/문구원장.md`

## 쓰는 법
- **교사 TV**: `index.html?host` → PIN(4~8자리) 입력 → [방 만들기] → 화면의 4자리 방 코드를 학생에게 → [연습](6턴 · 엘니뇨 없음) / [실전](24턴) · 왼쪽 위 [멈춤] · 오른쪽 아래 작은 아이콘 1.5초 길게 누르기 = 엘니뇨 앞당기기(D16 · 화면은 안 바뀜)
- **학생 휴대폰**: `index.html` → 방 코드 + 별명(1~8자) → [입장] → 가까운 바다 / 먼바다 / 쉬기 · [맡기기](누를 때마다 +1 · 마을 창고로)
- **교사 탭을 잃었을 때**: 같은 PC면 다시 열기만 하면 자동 복구 · 다른 PC면 처음 화면 아래 칸에 방 코드 + PIN → [입장]
- **수업 전날**: Supabase 대시보드에서 프로젝트가 «Paused»면 Resume(무료 요금제 7일 비활성 정지 — 공식 문서)

## 구현 중 고친 것(2026-10-31 ~ 11-01 · 실측에서 나온 것)
1. TV 그리기 캔버스가 판 위 단추를 덮어 클릭을 가로챔 → `pointer-events:none`
2. **남은 시간 · 카드 뒤집기마다 단추를 새로 만들어 터치가 사라짐** → 단추는 단계가 바뀔 때만 만들고 값은 제자리 갱신(E2E E12)
3. **첫 턴에 3D 장면을 처음 만들어 선택 시간이 멈춤**(소프트웨어 렌더 실측 10.9 s) → 대기실에서 미리 준비 · «시작» 방송 뒤 준비 시간 3 s · 3D 한 프레임이 이동 평균 70 ms를 넘기면 2D로 자동 전환
4. 학생 입장 RLS(insert … select의 RETURNING) → `002` · 연습 → 실전 턴 번호 겹침 → `003`(판 번호 g)
5. 엘니뇨 앞당김 기록 = «앞당길 때의 g.turn × 10 + 소식이 나갔는가» → 교사 복구 replay가 같은 시점에 다시 부름
6. 늦은 입장: 실전 중에는 RLS가 막음(입력칸 흔들림) — 판 사이(대기실)에는 입장 가능
